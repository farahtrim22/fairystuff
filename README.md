# 🌸 Fleurish - Sistem Informasi Penjualan & Rekomendasi Stok

## 📌 Deskripsi
Website berbasis Laravel untuk membantu pengelolaan penjualan dan rekomendasi stok bunga menggunakan metode TOPSIS.

## 🎯 Fitur
- Manajemen produk bunga
- Sistem pemesanan online
- Rekomendasi stok (TOPSIS)
- Dashboard admin

## 🛠️ Teknologi
- Laravel
- Filament
- Tailwind CSS
- MySQL

## ⚙️ Cara Menjalankan
```bash
git clone https://github.com/username/repo.git
cd repo
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
